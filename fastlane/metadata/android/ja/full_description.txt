BirdSocks は NetBird ネットワーク向けの非公式クライアントです。NetBird クライアントをユーザー空間ノードとして実行し、ローカルの SOCKS5 プロキシ経由でアプリにネットワークを提供します。そのため Android の VPN スロットを占有せず、別の VPN やファイアウォール、広告ブロッカーと並んで動作します。すべてのアプリをネットワークに接続したいときは、VPN（TUN）モードに切り替えるだけです。

NetBird Cloud でも、自前の NetBird サーバーでも動作します。

<b>ネットワーク</b>
• UDP に対応したローカル SOCKS5 プロキシ。ユーザー名とパスワードは任意で、ローカルネットワークからも利用可能にできます
• プロキシ経由でピア、ピアがルーティングするネットワーク、NetBird の DNS 名に到達。それ以外のインターネットへは直接、または出口ノード経由で接続
• ローカル DNS プロキシ: まず NetBird の名前を解決し、それ以外はネットワークのリゾルバーを使用
• VPN（TUN）モード: NetBird の範囲のみ、またはすべてのトラフィック。除外アプリも設定可能
• ピアは NetBird アドレスでスマートフォン自身のサービス（Wi-Fi 経由の adb、SSH サーバー、Web サーバー）に到達
• サーバーの NetBird リバースプロキシ経由で、ローカルポートに公開アドレスを付与

<b>管理</b>
• セットアップキーまたはブラウザーでサインイン。複数アカウントに対応
• ピアの接続経路、レイテンシ、通信量。ネットワークと出口ノード
• セッションの有効期限を事前に表示し、ブラウザーで延長
• 診断: イベント、ログ、アクセス確認、パケットキャプチャ、デバッグバンドル
• クイック設定タイル、再起動後の自動開始、birdsocks:// リンク
• Material 3、日本語・英語・ロシア語に対応

<b>ネットワークアクセス</b>
アプリは、選択した NetBird 管理サーバー（既定は NetBird Cloud）、そのシグナルサーバーとリレーサーバー、そしてピアと通信します。デバッグバンドルは、あなたが要求したときにのみ NetBird にアップロードされます。

<b>要件</b>
Android 7.0 以上、および NetBird Cloud または自前の NetBird サーバーのアカウント。root は不要です。
