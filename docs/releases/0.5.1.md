## ✨ Highlights

### 🛡️ The admin panel without NetBird running

The admin panel talks to your server's API over the phone's own network, never through NetBird, so it no longer asks you to start BirdSocks first. It opens on the active account whether NetBird is running or not; only signing in as this device still needs it.

### 🛡️ Админ-панель без запущенного NetBird

Админ-панель обращается к API сервера по обычной сети телефона, а не через NetBird, и больше не просит сначала запустить BirdSocks. Она открывается на активном аккаунте, запущен NetBird или нет; он нужен только для входа от имени этого устройства.
