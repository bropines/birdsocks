## ✨ Highlights

### 🛡️ An admin panel in the app

Your NetBird account, managed from the phone through the server's API with an access token sealed on the device. Open it from the shield on the main screen, a tile, Settings → Account or `birdsocks://admin`.

- A **home screen** with what needs you: peers and users awaiting approval, setup keys about to expire, and their actions right there.
- **Peers, groups and setup keys**: filters, renames, groups, expiration, invite QR codes for new keys.
- **Policies** in plain words ("Admins → Servers, TCP 22"), a **visual editor** and a **JSON mode**, templates, and "Who can reach…". Posture checks with an editor per type.
- **Networks, routes and DNS**, **users and tokens**, the **audit log**, every **account setting**, event streaming, identity providers and the reverse proxy.
- Read-only by default. Every change shows what it does before the screen lock, a risky one asks for the name typed back, and one that could cut this phone off says so.

### 🔓 Root mode beside another VPN

- With another VPN on the device, Root mode routes only NetBird's addresses, or the apps that VPN lets through. **Take the device anyway** overrides.
- NetBird's names go into **/etc/hosts**, so they resolve whichever DNS server Android picks, including the router's IPv6 one.
- The local network stays local, DNS waits for Android to validate the network, and nothing is left behind when BirdSocks is killed or updated.

### 🧩 And around the app

- **Settings search** in English and Russian, an **arrangeable main screen**, **home-screen widgets**, "Copy as…" on peers.
- An **Open-source licenses** screen with every component in the APK and its full text.
- NetBird **v0.83.1**.

### 🛡️ Админ-панель в приложении

Аккаунт NetBird прямо с телефона, через API сервера и с токеном доступа, запечатанным на устройстве. Открывается щитом на главном экране, плиткой, из «Настройки → Аккаунт» или по `birdsocks://admin`.

- **Главный экран** с тем, что ждёт вас: узлы и пользователи на одобрение, ключи установки, которые скоро истекут, и действия прямо там.
- **Узлы, группы и ключи установки**: фильтры, переименование, группы, срок входа, QR-приглашения для новых ключей.
- **Политики** человеческими словами («Админы → Серверы, TCP 22»), **визуальный редактор** и **режим JSON**, шаблоны и «Кто может достучаться…». Проверки состояния с редактором для каждого типа.
- **Сети, маршруты и DNS**, **пользователи и токены**, **журнал аудита**, все **настройки аккаунта**, стриминг событий, провайдеры входа и обратный прокси.
- По умолчанию только чтение. Каждое изменение показывает, что сделает, до запроса блокировки экрана; рискованное просит ввести имя, а то, что может отрезать этот телефон, предупреждает об этом.

### 🔓 Root рядом с другим VPN

- Если на устройстве есть другой VPN, режим Root ведёт через NetBird только его адреса или приложения, которые тот VPN пропускает. **Забирать устройство всегда** это отменяет.
- Имена NetBird попадают в **/etc/hosts** и резолвятся, какой бы DNS-сервер ни выбрал Android, включая IPv6-сервер роутера.
- Локальная сеть остаётся локальной, DNS ждёт, пока Android проверит сеть, а после убитого или обновлённого BirdSocks ничего не остаётся.
