# Дорожная карта BirdSocks

Что есть в 0.1.0 — в [`CHANGELOG.md`](../CHANGELOG.md). Здесь то, что дальше,
примерно по порядку.

## Проверить на устройствах
- Вход через браузер и по ключу установки, в NetBird Cloud и на своём сервере.
- Прямые (P2P) соединения из песочницы приложения с патчем 03; relay как запасной путь.
- Прокси: адреса сети, DNS-имена NetBird, интернет напрямую и через выходной узел.
- Переключения Wi-Fi ↔ мобильная сеть (см. монитор сети ниже).

## Дальше
- **Режим TUN** через `hev-socks5-tunnel` поверх SOCKS5 (как в TailSocks), с
  исключением приложений.
- **Прокси для управляющих соединений и обход DPI.** У номеронабирателей NetBird
  нет поддержки прокси; патч `client/net.Dialer` для management, signal и relay,
  вернуть ByeDPI. `NB_RELAY_TRANSPORT=ws` уже переводит relay на WebSocket.
- **Истечение сессии**: предупреждения приходят в SubscribeEvents; показывать их
  и предлагать `RequestExtendAuthSession`.
- **HTTP-прокси** рядом с SOCKS5 — для приложений, которые умеют только HTTP.
- Виджеты, действия Tasker, резервные копии — были в TailSocks; перенести то, что подходит.

## Потом
- Root-режим.
- Нативный TUN на собственном Android-коде NetBird.
- F-Droid (воспроизводимые сборки, все четыре ABI), Weblate.
- Свой логотип и скриншоты.
