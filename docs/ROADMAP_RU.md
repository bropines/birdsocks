# Дорожная карта BirdSocks

Что есть в 0.1.0 — в [`CHANGELOG.md`](../CHANGELOG.md). Здесь то, что дальше,
примерно по порядку.

## Проверить на устройствах
- Режим VPN: DNS через 198.18.0.2, маршруты с выходным узлом и без, исключённые
  приложения, падение демона роняет VPN, постоянный VPN, частный DNS
  «автоматически». Пересборка должна обновлять сеть VPN на месте.
- Вход через браузер и по ключу установки, в NetBird Cloud и на своём сервере.
- Прямые (P2P) соединения из песочницы приложения с патчем 03; relay как запасной путь.
- Прокси: адреса сети, DNS-имена NetBird, интернет напрямую и через выходной узел.
- Переключения Wi-Fi ↔ мобильная сеть (см. монитор сети ниже).
- Подключение к серверу через SOCKS5/HTTP-прокси и через ByeDPI (патч 08).
- Релизная R8-сборка на устройстве.
- Режим Root с включённым частным DNS, на KernelSU и Magisk и рядом с VPN-приложением, кроме нашего брата.
- Записи панели администратора на живом сервере (чтение проверено на своём), NetBird Cloud, вход как это устройство.

## Дальше
- **HTTP-прокси** рядом с SOCKS5 — для приложений, которые умеют только HTTP.
- **Панель администратора**: токен через SOCKS5-прокси с паролем; истекающие токены на главном экране панели; приглашения по e-mail; временный доступ.
- **Weblate**: проект на сервисе, когда репозиторий станет публичным (docs/TRANSLATING_RU.md).
